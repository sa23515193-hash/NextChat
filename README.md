# NextChat

A polished real-time-chat inspired portfolio application with a premium landing page, authentication UI, messaging, media sharing, voice messages, reactions-ready UI, search, responsive design and customizable chat wallpapers.

## Frontend demo
```powershell
npm install
npm run dev
```
Open the local URL shown by Vite. Demo sign-in works without a backend.

## GitHub Pages
Build with `npm run build` and deploy the `dist` folder using GitHub Pages. Vite is configured with a relative base so repository paths work.

## Demo accounts
Use the demo button on the sign-in page.

## Note
Microphone recording requires browser permission and HTTPS (or localhost). Attachments in this frontend-only edition use browser object URLs and are intended for demo use.
